
Project Overview

Artificial intelligence in taxation uses Multilayer Perceptron for automated compliance classification, Artificial Neural Networks for real time anomaly and fraud detection, Gradient Boosting for audit risk scoring prioritization, Robotic Process Automation combined with Natural Language Processing for intelligent financial data extraction. It also incorporates NLP with Retrieval-Augmented Generation to provide tax accountants with immediate access to relevant regulations and past cases. The system was built using design science methodology, creating artifacts such as BPMN, use case diagram , user stories, and prototype.
