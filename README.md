# AI-in-Taxation

A thesis project proposing an intelligent system that leverages Artificial Intelligence to enhance tax compliance, automate fraud detection, and support audit prioritization.

---

## Project Overview

Modern tax authorities face growing challenges including tax evasion, fraud, and the complexity of digital financial transactions that traditional rule-based systems cannot effectively handle. This project proposes an AI-driven system that integrates multiple machine learning and NLP techniques to address these challenges across five core requirements (REQ-1 to REQ-5).
